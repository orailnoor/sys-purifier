# System Purifier

System Purifier is a professional, privacy-first GUI tool designed to safely remove bloatware and tracking components from Android devices.

## Features

- **Safe Removal**: Validates packages against a risk database to prevent removing critical system components.
- **Backup & Restore**: Automatically backs up applications before removal, including split APKs, ensuring you can always restore if something goes wrong.
- **Multiple Devices**: Supports managing multiple connected Android devices seamlessly.
- **Privacy Score**: Analyzes your device to provide a privacy score based on the number of known trackers installed.
- **No Dependencies**: Works out of the box with bundled ADB binaries—no Android SDK required.

## Disclaimer

Use this tool at your own risk. While System Purifier provides safeguards, removing core system packages can lead to system instability, disabled push notifications, or boot loops. Always keep a backup.
