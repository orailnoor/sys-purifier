# Security Policy

## Supported Versions
We only support the latest release of System Purifier.

## Reporting a Vulnerability
If you discover a security vulnerability within System Purifier, please open an issue in the project's repository. Do not share the exploit publicly until a patch has been released.

Since System Purifier executes ADB commands, command injection vulnerabilities are taken very seriously. If you find any input vector that can bypass the intended arguments, please report it immediately.
