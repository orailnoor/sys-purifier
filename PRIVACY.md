# Privacy Policy

System Purifier is a privacy-first tool. 

## Data Collection
We collect **zero** telemetry, analytics, or crash reports. All operations are performed entirely locally on your machine and the connected Android device.

## Network Access
System Purifier does not make any outbound network requests. It operates fully offline.

## File Access
System Purifier requires access to:
- Read device data via ADB.
- Write backup files to your local disk (e.g., Desktop/DeGoogle_Backups).

Your data remains entirely on your devices.
